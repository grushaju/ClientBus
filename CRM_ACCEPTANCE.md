## Исправление, найденное живой приёмкой

Реальный R08 возвращает два HTML-фрагмента: строки с `append=".company-clients tbody"` и счётчик с `container=".company-clients .count-items"`. Прежний адаптер считал такой ответ неоднозначным. Теперь выбираются строки, а известное обновление счётчика игнорируется как метаданные; дубли строк, неизвестная цель и противоречивые цели по-прежнему дают ошибку.

Последняя порция содержит не пустую строку, а единственный `tr/td.red.text-center[colspan]` с текстом «Ничего не найдено». Принимается только этот проверенный маркер или явно пустой HTML. Произвольный баннер, сообщение об отказе доступа и HTML без строк не становятся успешной пустой страницей. Полнота остаётся `UNKNOWN`, содержимое callback/script не исполняется. Три новые регрессии воспроизвели исходную ошибку до исправления; затем прошёл весь контракт R08 и оба живых диапазона.

## Повторение

Обычная регрессия не требует DIKIDI и не выбирает класс `CrmDikidiReadAcceptance`:

```powershell
mvn -o -pl server -am test-compile org.apache.maven.plugins:maven-surefire-plugin:3.5.6:test -l server/target/crm-acceptance-12-4-6-final-server.log
npm --prefix .\ui test
npm --prefix .\ui run test:e2e:types
npm --prefix .\ui run test:e2e -- --reporter=line --max-failures=4
npm --prefix .\ui run build
mvn -o -pl server -am process-resources
```

Для живого чтения класс выбирается явно и дополнительно включается свойством `clientbus.crm.acceptance.live=true`. Нужны доступ к настроенной локальной БД и сохранённому ключу, действующий CONNECTED аккаунт и включённый проект. Если проектов несколько, требуется локальный UUID `projectId` либо `workspaceId`; без выбора тест останавливается до открытия credentials и сетевого чтения.

```powershell
$crmAcceptanceProject = 'локальный UUID проекта CRM'
mvn -o -pl server -am '-Dtest=CrmDikidiReadAcceptance' '-Dsurefire.failIfNoSpecifiedTests=false' '-Dclientbus.crm.acceptance.live=true' "-Dclientbus.crm.acceptance.projectId=$crmAcceptanceProject" '-Dclientbus.crm.acceptance.dateFrom=2026-10-27' '-Dclientbus.crm.acceptance.dateTo=2026-11-02' test-compile org.apache.maven.plugins:maven-surefire-plugin:3.5.6:test
```

Один запуск ограничен семью включительными датами, тремя порциями клиентов, пятью мастерами и 160 HTTP-вызовами. Разрешённые маршруты и секции journal перечислены в транспортной обёртке; остальные запросы отклоняются. Необязательный `clientbus.crm.acceptance.diagnostics=true` печатает только структуру ответов R08 и счётчики, без значений полей клиентов. Credentials/key не передаются через аргументы Maven и не сохраняются тестом.
